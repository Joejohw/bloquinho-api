# Repositórios

A solução Bloquinho é dividida em três repositórios:

| Repositório | Responsabilidade | Estado conhecido |
|---|---|---|
| `bloquinho-api` | Backend, regras de negócio, segurança, persistência e contratos HTTP | Este repositório; remoto `origin` configurado em `https://github.com/Joejohw/bloquinho-api.git` |
| `bloquinho-admin` | Interface administrativa Angular | Repositório separado; estado não verificado por esta documentação |
| `bloquinho-web` | Interface pública Angular | Repositório separado; estado não verificado por esta documentação |

No `bloquinho-api`, a branch confirmada no commit `5ccd280` é `main`, acompanhando `origin/main`.

Este documento não afirma visibilidade pública ou privada dos repositórios remotos, pois essa propriedade não pode ser confirmada pelos arquivos locais. Também não prescreve comandos de criação de repositório: o remoto da API já existe.

Para o estado funcional do backend, consulte [CURRENT_STATE.md](CURRENT_STATE.md).
